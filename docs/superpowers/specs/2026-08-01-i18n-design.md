# i18n 国际化设计文档

## 概述

为無名の主页项目添加国际化（i18n）支持，实现中英文双语切换，覆盖主站前端、语音播报文本、管理后台三部分。

## 技术选型

- **主站**：已安装的 `vue-i18n@11.4.5`，Composition API 模式（`useI18n`）
- **后台**：`i18next`（CDN 引入，单文件无需构建），配合 `data-i18n` 属性自动替换文本
- **语言检测**：首次访问读 `navigator.language`，中文系 → `zh-CN`，其他 → `en`
- **语言持久化**：主站存入 Pinia store（`localStorage.language`），后台独立存储（`localStorage.admin-lang`）

## 架构

```
src/i18n/
├── index.ts              # vue-i18n 初始化、语言检测
└── locales/
    ├── zh-CN.json         # 主站中文语言包（按模块分组）
    └── en.json            # 主站英文语言包

admin-server/
├── locales/
│   ├── zh-CN.json         # 后台中文语言包
│   └── en.json            # 后台英文语言包
└── public/
    └── index.html         # 引入 i18next（CDN），元素加 data-i18n
```

### i18n 初始化（src/i18n/index.ts）

```typescript
import { createI18n } from 'vue-i18n'
import zhCN from './locales/zh-CN.json'
import en from './locales/en.json'

function detectLanguage(): 'zh-CN' | 'en' {
  const saved = localStorage.getItem('language')
  if (saved === 'zh-CN' || saved === 'en') return saved
  return navigator.language.startsWith('zh') ? 'zh-CN' : 'en'
}

const i18n = createI18n({
  legacy: false,
  locale: detectLanguage(),
  fallbackLocale: 'zh-CN',
  messages: { 'zh-CN': zhCN, en },
})

export default i18n
```

### Store 集成

在 state 中新增 `language: 'zh-CN' as 'zh-CN' | 'en'`，并加入 `CONFIGURABLE_DEFAULT_KEYS`，使后台可配置默认语言。

### i18n 初始化脚本

```javascript
async function initI18n() {
  const saved = localStorage.getItem('admin-lang') ||
                (navigator.language.startsWith('zh') ? 'zh-CN' : 'en')
  try {
    const [zh, en] = await Promise.all([
      fetch('/admin/locales/zh-CN.json').then(r => r.json()),
      fetch('/admin/locales/en.json').then(r => r.json())
    ])
    i18next.init({ lng: saved, fallbackLng: 'zh-CN', resources: { 'zh-CN': { translation: zh }, en: { translation: en } } })
    applyTranslations()
  } catch (e) {
    console.error('语言包加载失败，回退到内联中文')
  }
}

function applyTranslations() {
  document.querySelectorAll('[data-i18n]').forEach(el => {
    el.textContent = i18next.t(el.getAttribute('data-i18n'))
  })
}

function changeLanguage(lang) {
  i18next.changeLanguage(lang)
  localStorage.setItem('admin-lang', lang)
  applyTranslations()
}
```

## 语言切换与数据流

### 主站设置面板

在 `src/views/MoreSet/index.vue` 添加语言切换选项：

```vue
<div class="set-item">
  <span class="label">{{ t('set.language') }}</span>
  <select v-model="language">
    <option value="zh-CN">{{ t('set.zhCN') }}</option>
    <option value="en">{{ t('set.en') }}</option>
  </select>
</div>
```

```typescript
const language = computed({
  get: () => store.language,
  set: (val) => {
    store.language = val
    locale.value = val
    localStorage.setItem('language', val)
  }
})
```

### 数据流

```
首次访问:
  navigator.language → 'zh' 开头? → zh-CN : en
  → i18n.locale = 检测结果
  → store.language = 检测结果（持久化到 localStorage）

用户切换:
  设置面板选择 → store.language = 新值
  → i18n.locale = 新值（立即响应）
  → localStorage.language = 新值（持久化）

后台默认配置:
  /api/defaults → language: 'zh-CN'
  → store 初始化时读取（CONFIGURABLE_DEFAULT_KEYS 包含 language）
  → 新访客使用后台配置的默认语言
```

### <html lang> 同步

```typescript
watch(() => store.language, (lang) => {
  document.documentElement.lang = lang
}, { immediate: true })
```

## 错误处理与边界情况

### 语言包加载失败

- 主站语言包是静态 import，构建时打包进 JS，不会加载失败
- 后台语言包通过 fetch 加载，失败时回退到 HTML 中已有的硬编码文本（data-i18n 不替换即显示原文本）

### 动态文本（含变量）

需要插值的场景：

```json
{ "weather": { "feelsLike": "体感 {temp}°", "humidity": "湿度 {value}%" } }
```

```typescript
t('weather.feelsLike', { temp: 25 })  // "体感 25°"
```

### 不翻译的内容

- 天气 API 返回的天气描述
- 一言 API 返回的句子
- 歌曲名、艺术家名
- 用户自定义的站点名称、链接名称等

### 已知限制

1. **语音播报**：Azure TTS 的 voice 需根据语言切换
2. **日期格式**：dayjs 已支持 locale，切换时同步 `dayjs.locale(lang === 'zh-CN' ? 'zh-cn' : 'en')`
3. **后台与主站语言独立**：后台用 `localStorage.admin-lang`，主站用 `localStorage.language`，互不干扰
